# Courses

## Задание

Создать сетку из 14 тем в два столбца с изображениями и количеством курсов.

## Выполнено

Созданы класс Topic, источник данных и карточка темы. Использованы LazyVerticalGrid, строковые ресурсы и тематические изображения. Интерфейс переведён на русский, изображения заменены мемами с котиками.
