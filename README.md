# Лабораторная работа № 4

## Задание

Изучить прокручиваемые списки в Jetpack Compose. Создать приложение Affirmations и сетку тематических карточек в два столбца.

## Выполнено

Подготовлены два отдельных Android-проекта на Kotlin с минимальным SDK 24: Affirmations и Courses. В Affirmations список из десяти карточек реализован через LazyColumn. В Courses четырнадцать тем представлены через LazyVerticalGrid. Данные описаны классами, тексты и изображения вынесены в ресурсы. Подписи переведены на русский, вместо исходных фотографий использованы мемы с котиками.
